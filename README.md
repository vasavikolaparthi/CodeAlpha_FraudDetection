# CodeAlpha_FraudDetection

## 📘 Description
This project is a hands-on Machine Learning mini project focused on Fraud Detection. The objective was to build and evaluate different supervised classification models to accurately identify fraudulent transactions and compare their performance on a given dataset.

## 📊 Models Used
-Logistic Regression
-Random Forest
-Decision Tree

## 🏆 Results
-Logistic Regression: 94% accuracy
-Random Forest: 95% accuracy
-Decision Tree: 90% accuracy

Among the tested models, Random Forest achieved the highest accuracy, making it the most effective model for this fraud detection task. The results were visualized using a bar chart for clear and easy comparison.

## 🛠 Technologies Used
-Python
-Jupyter Notebook
-Scikit-learn
-Matplotlib / Seaborn
-Pandas / NumPy

## ✨ Motivation
This project was developed to strengthen my understanding of classification algorithms, model evaluation, and their application in real-world problem scenarios like fraud detection, based on my foundational learning in Machine Learning.
